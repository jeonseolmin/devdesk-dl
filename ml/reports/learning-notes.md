# 수업·학습용 포인트 (받은 데이터 기준)

DevDesk ML1과 별개로, 같은 데이터로 머신러닝 개념을 연습하기 좋은 주제들. 위에서부터 쉬운 순.

## 1. 원시 로그 → 특징 만들기 (Kaggle 2명)
- 이벤트 단위 TSV(창 전환, 키, 유휴)를 1분 창으로 집계 → 특징 공학의 기본(windowing, resample, rolling 5/15분).
- 라벨(5~30분 간격)을 가장 가까운 과거 시점 특징에 붙이기 → `pandas.merge_asof`. 미래 정보가 섞이지 않게(누수).

## 2. 분류 + 올바른 검증 (SWELL-KW)
- `Condition`(R/N/T/I) 다중 분류, `Stress` 회귀 → 같은 특징으로 분류/회귀 비교.
- 25명 → **GroupKFold / leave-one-subject-out**. 랜덤 분할과 점수 차이를 직접 보면 "사람 간 누수"가 체감됨.
- `Stress` 결측 451행 → 결측 처리 방식 비교.

## 3. 약지도 학습·라벨 노이즈 (BEHACOM, ML1 본편)
- 규칙으로 만든 라벨(focus/distracted/break)로 학습 → 모델이 규칙을 그대로 외우는지, 규칙에 없는 특징을 쓰는지 확인.
- 규칙에 쓴 특징을 입력에서 빼고 학습해 보기(순환 논리 점검).
- 클래스 불균형(focus 적음) → class_weight, PR-AUC, macro-F1.
- 시간 기준 분할(앞 날짜 학습, 뒤 날짜 평가)과 랜덤 분할 비교.

## 4. 고차원 데이터·차원 축소 (BEHACOM 원본 zip, 선택)
- `USER`(12명) 맞히기 = 키 입력 습관으로 사용자 식별. 원본은 키 쌍(digraph) 컬럼 약 12,000개, 대부분 0인 희소 행렬.
- 연습거리: 희소 행렬(`scipy.sparse`), 특징 선택(분산·상호정보량), PCA/TruncatedSVD, 차원의 저주, 사용자별 데이터 불균형(179~55,778행).
- 만들기: `ml/scripts/slim_behacom.py`의 `DROP`을 비우거나 바꿔 원하는 컬럼만 뽑기(전체를 풀면 5.7GB).
- 주의: 타이핑 생체인식이라 DevDesk 기능에는 쓰지 않음(계획서 범위 밖). 순수 학습용.

## 공통 체크리스트
- 분할 → 전처리(스케일러·인코더는 학습셋에만 fit) → 학습 → 평가 순서 지키기.
- 기준선(가장 많은 클래스, 규칙 그대로) 점수를 먼저 기록하고 모델과 비교.
- 결과는 `ml/reports/`에 지표와 함께 기록.
